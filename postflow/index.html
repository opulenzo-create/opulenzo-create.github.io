Social publishing for creators

Make every post flow.

Postflow is a Windows desktop application for organizing your own short-form videos, scheduling posts and tracking publishing outcomes across supported social platforms.

Desktop application · Currently in development. This website provides project and legal information; no public download is offered here.

Video library

Import original video files and check supported technical formats.

Publishing queue

Plan uploads for YouTube, TikTok and Instagram, subject to each platform's permissions and API limits.

Reliable status

Track scheduled, blocked, failed and confirmed posts without mistaking an attempt for publication.

How Postflow works

Creators authorize supported platform connections using their own accounts. In the current local prototype, video files, schedules and API credentials are stored on the creator's Windows computer. Authorized uploads and status checks use official platform APIs.

Postflow is an independent software project, not a product endorsed by TikTok, Meta, Instagram, Google or YouTube. Additional public integrations require the relevant platform approvals.
